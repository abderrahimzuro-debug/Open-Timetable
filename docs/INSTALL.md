# التثبيت والتجربة — Open-Timetable (واجهة FET الحديثة)

هذا الدليل يشرح كيف تُنزّل البرنامج وتثبّته وتجرّبه على **جهاز في المؤسسة**، وكيف تشخّص أي مشكلة.

> النسخة الحالية: مبنية على **FET 7.12.0** (AGPL-3.0) + واجهة Open-Timetable (مظهر حديث، عربية،
> شريط جانبي، لوحة بداية، نشر إلى مجلد مشترك).
>
> **الحزم مُختبرة فعليًا:** Linux (Qt 5.15.3) وويندوز (Qt 6.10 + MinGW 13.1) — كلتاهما تبني
> وتجتاز الفحص الذاتي للواجهة (`SELFCHECK OK`).

---

## 1) ما تحتاج تنزيله

1. افتح صفحة سير العمل في المستودع:
   `https://github.com/abderrahimzuro-debug/Open-Timetable/actions/workflows/engine.yml`
2. اختر **آخر تشغيل ناجح** (علامة ✓ خضراء).
3. انزل إلى قسم **Artifacts** وحمّل ما يناسب نظامك:

| الحزمة | الحجم | للنظام | المحتوى |
| --- | --- | --- | --- |
| `open-timetable-windows-x86_64` | ≈24 MB | ويندوز 10/11 (64-بت) | ملف ZIP فيه `Open-Timetable.exe` + كل مكتبات Qt وMinGW داخل المجلد (**لا تحتاج تثبيت Qt**) + `translations/fet_ar.qm` + `LICENSE` + `INSTALL.md` |
| `open-timetable-gui-linux-x86_64` | ≈20 MB | لينكس | `fet`، `fet-cl`، `translations/`، وملف جاهز `open-timetable-linux-x86_64.tar.gz` (فيه `run.sh`) |
| `fet-cl-7.12.0-upstream-linux-x86_64` | ≈3 MB | لينكس (سيرفر) | محرّك FET الأصلي غير المعدّل (للمقارنة/الأتمتة) |
| `gui-build-log-ours` / `windows-selfcheck` | صغيرة | تشخيص | سجل البناء + تقرير الفحص الذاتي |

> حزمة ويندوز تُبنى تلقائيًا مع كل تعديل يمسّ الواجهة (≈25 دقيقة) وتُرفَق في نفس التشغيل.

## 2) التثبيت على ويندوز (الأكثر شيوعًا)

1. فكّ ضغط `open-timetable-windows-x86_64.zip` إلى مجلد ثابت، مثل:
   `C:\Open-Timetable\`
   > **لا تشغّله من داخل ملف ZIP** — Qt يحتاج مكتباته بجانب الملف التنفيذي.
2. شغّل `Open-Timetable.exe`.
3. قد يظهر تحذير **SmartScreen** («Windows protected your PC») لأن الملف غير موقّع رقميًا:
   اضغط **More info ▸ Run anyway**.
   > لتجنّبه نهائيًا: زر يمين على الملف ▸ Properties ▸ **Unblock**.
4. (اختياري) اختصار على سطح المكتب: زر يمين على `Open-Timetable.exe` ▸ **Send to ▸ Desktop**.
5. (اختياري) تثبيت خط عربي جميل: **Cairo** أو **Noto Naskh Arabic** — البرنامج يستعمله تلقائيًا
   إن وجده، وإلا يستعمل خط النظام.

**لا تحتاج صلاحيات مدير**، ولا تثبيت Qt، ولا اتصال إنترنت لتشغيل البرنامج.

---

## 3) التثبيت على لينكس

### أ) من الملف المضغوط (الأسهل)
```bash
tar -xzf open-timetable-linux-x86_64.tar.gz
cd open-timetable-linux-x86_64

# المكتبات المطلوبة (مرة واحدة)
sudo apt install libqt5widgets5 libqt5printsupport5 libqt5network5   # Debian/Ubuntu
# أو: sudo dnf install qt5-qtbase-gui qt5-qtbase

./run.sh
```

### ب) من الملفات المفردة
```bash
mkdir -p ~/open-timetable && cd ~/open-timetable
# ضع fet و fet-cl و translations/ هنا ثم:
mv fet open-timetable && chmod +x open-timetable fet-cl
./open-timetable
```

### ج) بناء محلي (للمطوّرين)
```bash
sudo apt install build-essential qtbase5-dev qtbase5-dev-tools qttools5-dev-tools
git clone https://github.com/abderrahimzuro-debug/Open-Timetable.git
cd Open-Timetable
mkdir -p build/gui && cd build/gui
qmake ../../fet/fet.pro CONFIG+=release
make -j"$(nproc)"
cp ../../build/translations/fet_ar.qm .   # بعد تشغيل scripts/fet-build-translations.sh ar
./fet
```

## 4) أول تشغيل: ماذا تتوقّع؟

1. **اللغة عربية افتراضيًا** والواجهة من اليمين إلى اليسار (RTL).
2. **الشريط الجانبي** على اليمين: لوحة البداية • الواجهة الكلاسيكية • البيانات • القيود •
   التوليد والجداول • النشر.
3. **لوحة البداية**: اسم المؤسسة، مسار الملف، حالة التوليد، 9 بطاقات أعداد، 12 إجراءً سريعًا.
   قبل فتح أي ملف تظهر الأعداد `—` وهذا طبيعي.
4. اضغط **«الواجهة الكلاسيكية»** لتصل إلى أزرار FET الأصلية كلها (لم تُحذف أي وظيفة).

### إن ظهرت الواجهة بالإنجليزية
- قائمة **Settings ▸ Language** (أو الإعدادات) ▸ اختر **العربية (ar)**.
- أو من ملف الإعدادات: أغلق البرنامج، ثم `%APPDATA%\fet\fettimetabling.ini` على ويندوز
  (`~/.config/fet/fettimetabling.ini` على لينكس) واضبط `language=ar`.

## 5) الفحص الذاتي (أسرع طريقة للتأكد أن كل شيء سليم)

من سطر الأوامر في مجلد البرنامج:

```bash
# ويندوز (PowerShell)
$env:QT_QPA_PLATFORM="offscreen"; .\Open-Timetable.exe --ot-selfcheck

# لينكس
QT_QPA_PLATFORM=offscreen ./open-timetable --ot-selfcheck
```

المخرجات الفعلية (من تشغيل CI على ويندوز، Qt 6.10):

```
===== Open-Timetable self-check =====
         Qt: 6.10.0
         platform: offscreen
  [ok]   النافذة الرئيسية موجودة
  [ok]   ورقة الأنماط (QSS) مطبّقة — 6504 حرفًا
  [ok]   الشريط الجانبي مثبّت
  [ok]   قائمة التنقّل موجودة — 21 عنصرًا
  [ok]   الصفحات موجودة — 2 صفحات
  [ok]   لوحة البداية موجودة
  [ok]   تحديث لوحة البداية يعمل
  [ok]   كل إجراءات الشريط الجانبي مرتبطة — 15/15
```

`SELFCHECK OK` = التثبيت سليم. أي `[FAIL]` يخبرك بالجزء المعطّل مباشرة.

## 6) أول جدول في 10 دقائق (مسار سريع)

1. **ملف ▸ جديد**.
2. **الأقسام والأفواج**: أضف قسمًا (مثل «1AS») وفوجًا واحدًا على الأقل.
3. **المواد**: أضف 3–4 مواد.
4. **الأساتذة**: أضف أستاذين.
5. **القاعات**: أضف قاعتين.
6. **الأنشطة**: أضف نشاطًا لكل (مادة × أستاذ × فوج) بمدة 2.
7. **القيود** (اختياري في التجربة الأولى): توفّر أستاذ، أقصى حصص يوميًا.
8. **توليد الجدول** ▶ انتظر حتى ينتهي.
9. **جداول الأقسام / جداول الأساتذة** ▶ راجع النتيجة.
10. **ملف ▸ تصدير ▸ نشر الجداول إلى مجلد مشترك…** ▶ اختر مجلدًا ▶ سيفتح لديك
    `index.html` مع كل الجداول منظّمة بالعربية. راجع `docs/PUBLISH.md` للمشاركة على الشبكة.

## 7) حل المشاكل الشائعة

| المشكلة | السبب المحتمل | الحل |
| --- | --- | --- |
| «لا يمكن تشغيل التطبيق» / خطأ DLL ناقص (ويندوز) | فُكّ الضغط ناقصًا أو شُغّل من داخل ZIP | أعد الفكّ كاملًا إلى مجلد عادي، وتأكد من وجود مجلد `platforms\` بجانب الملف التنفيذي |
| خطأ `could not find or load the Qt platform plugin "windows"` | ملفات Qt ناقصة | أعد تحميل الحزمة الكاملة (فيها `platforms/qwindows.dll`) |
| البرنامج يعمل لكن النص العربي مربّعات | لا يوجد خط عربي | ثبّت Cairo / Noto Naskh Arabic، أو غيّر الخط من **Settings ▸ Font** |
| ظهرت رسالة في شريط الحالة: الترجمة مفقودة | مجلد `translations` غير موجود بجانب التنفيذي | تأكد من فكّ الحزمة كاملة (فيها `translations/fet_ar.qm`). البرنامج يعمل بالإنجليزية بدلًا من العربية — ولم يعد يوقف التشغيل بمربّع حوار |
| الواجهة من اليسار لليمين | اللغة إنجليزية | Settings ▸ Language ▸ العربية |
| لوحة البداية تعرض `—` | لم يُفتح ملف بعد | طبيعي: افتح ملفًا أو ابدأ ملفًا جديدًا |
| أزرار الشريط الجانبي لا تعمل | بيانات غير محمّلة | بعض الإجراءات تتطلب ملفًا مفتوحًا؛ ابدأ ملفًا جديدًا أولًا |
| «تعذّر إنشاء المجلد» عند النشر | صلاحيات المجلد المشترك | اختر مجلدًا لديك صلاحية كتابة عليه، أو انشر محليًا ثم انسخ |
| الجدول لا يُولّد (يستغرق طويلًا) | قيود متعارضة | راجع **التعارضات**، خفّف القيود، وأعد التوليد |
| `error while loading shared libraries: libQt5Widgets.so.5` (لينكس) | Qt5 غير مثبّت | `sudo apt install libqt5widgets5 libqt5printsupport5` |

### تشخيص متقدّم
```bash
# لینكس: تفاصيل أكثر
QT_DEBUG_PLUGINS=1 ./open-timetable 2>&1 | head -50

# ويندوز (PowerShell): عرض مكتبات Qt المستخدمة
.\Open-Timetable.exe --ot-selfcheck
```

## 8) التحديث والإزالة

- **التحديث:** احتفظ بمجلد الإعدادات، واستبدل مجلد البرنامج بالحزمة الجديدة.
  ملفاتك (`.fet`) خارج مجلد البرنامج ولا تتأثر.
- **إزالة ويندوز:** احذف المجلد + `%APPDATA%\fet` (الإعدادات).
- **إزالة لينكس:** احذف المجلد + `~/.config/fet`.

---

## 9) أين ملفاتك؟

| النوع | المسار |
| --- | --- |
| ملفات البيانات | أينما حفظتها (افتراضيًا: مجلّد المستخدم) |
| مخرجات التوليد | `~/fet-results` (يُضبط من Settings) |
| مجلدات النشر | ما تختاره عند النشر (يُتذكّر آخر مجلد) |
| الإعدادات (ويندوز) | `%APPDATA%\fet\fettimetabling.ini` |
| الإعدادات (لينكس) | `~/.config/fet/fettimetabling.ini` |

## 10) ماذا أُصلح في جولة «التثبيت والتجربة» هذه؟

| المشكلة | كانت | صارت |
| --- | --- | --- |
| ملف الترجمة مفقود | **مربّع تحذير معطِّل عند كل إقلاع** (البرنامج لا يبدأ حتى تضغط OK) | رسالة في شريط الحالة + سجل، ويكمل بالإنجليزية |
| بناء ويندوز بـ MSVC | يفشل: `fatal error C1061: blocks nested too deeply` في `rules.cpp` | يُبنى بـ **MinGW 13.1** (نفس أدوات FET الرسمية) |
| التأكد من أن الواجهة تعمل | لا وسيلة غير الفتح اليدوي | أمر `--ot-selfcheck` يفحص 9 نقاط ويعيد رمز خروج |
| حزمة ويندوز | لا توجد | ZIP محمول (Qt مضمّن) ≈24 MB يُبنى آليًا |
