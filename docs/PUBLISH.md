# نشر الجداول إلى مجلد مشترك (الخيار «أ»)

القرار: **برنامج سطح مكتب على جهاز في المؤسسة** + **المدير ينشر الجداول في مجلد مشترك**،
ويقرأها الأساتذة والتلاميذ من المتصفح. لا خادم، لا حسابات، لا كلمات مرور — أبسط حل يخدم
الأدوار الثلاثة.

## كيف يعمل؟

```
جهاز المدير (برنامج Open-Timetable / FET)
│
│ 1) يُدخل البيانات ويولّد الجدول
│ 2) File ▸ Export ▸ «نشر الجداول إلى مجلد مشترك…»
│ 3) يختار مجلد النشر (مثلًا: Z:\الجداول  أو  \\SERVER\Timetables)
▼
مجلد النشر
└── <اسم المؤسسة>-<التاريخ_الساعة>/
    ├── index.html                 ← نقطة البداية (عربية، RTL)
    ├── README.txt                 ← تعليمات للمستخدمين
    ├── fet-index.html             ← صفحة FET الأصلية (نسخة احتياطية)
    ├── <prefix>teachers_time_horizontal.html
    ├── <prefix>teachers_days_horizontal.html
    ├── <prefix>years_days_horizontal.html  … إلخ
    ├── <prefix>activities.xml / teachers.xml / subgroups.xml
    ├── <prefix>soft_conflicts.txt
    └── source.fet                 ← ملف البيانات الأصلي (لإعادة الفتح)
▲
│ 4) الأساتذة والتلاميذ يفتحون index.html من أي متصفح
▼
أستاذ → قسم «جداول الأساتذة» → Ctrl+F لاسمه
تلميذ → قسم «جداول الأفواج والسنوات» → قسمه
الطباعة: Ctrl+P (الصفحة مهيّأة للطباعة)
```

## ماذا يفعل الزر بالضبط؟

1. يتحقّق أن الجدول **مولّد** فعلًا (وإلا يطلب التوليد أولًا).
2. يسأل عن **مجلد النشر** ويتذكّر آخر اختيار.
3. ينشئ مجلدًا جديدًا باسم `المؤسسة-YYYY-MM-DD_HHmm` — **لا يكتب فوق نشر سابق أبدًا**
   (يضيف `-2`, `-3` عند التكرار).
4. يكتب داخله كل ملفات FET: جداول الأساتذة / السنوات / الأفواج / الفرق / القاعات /
   المباني / المواد / وسوم الأنشطة، بصيغتي «الأيام × الحصص» و«الأسابيع × الحصص»،
   مع الإحصاءات وملفات XML وسجل التعارضات.
5. ينسخ ملف البيانات الأصلي إلى `source.fet`.
6. يُعيد تسمية صفحة FET إلى `fet-index.html` ويكتب **صفحة بداية عربية** `index.html`
   مقسّمة إلى بطاقات: الأفواج والسنوات / الأساتذة / القاعات / ملفات أخرى.
7. يكتب `README.txt` بالتعليمات.
8. يعرض رسالة نجاح فيها المسار وعدد الصفحات، وزر **«فتح المجلد»**.

## مشاركة المجلد على شبكة المؤسسة

### ويندوز (الأكثر شيوعًا)
1. أنشئ مجلدًا مثل `D:\Timetables`.
2. زر يمين ▸ **خصائص** ▸ **المشاركة** ▸ مشاركة مع القراءة فقط (Read-only) — الأساتذة لا
   يحتاجون الكتابة.
3. الأساتذة يفتحون: `\\اسم-الجهاز\Timetables\index.html` (أو بمسح رمز QR للرابط).

### لينكس (سامبا)
```ini
# /etc/samba/smb.conf
[Timetables]
   path = /srv/timetables
   browseable = yes
   read only = yes
   guest ok = yes
```

> نوصي بمشاركة **للقراءة فقط**: كل تعديل/نشر يبقى من جهاز المدير فقط.

## الطبع والتوزيع

- **الطباعة:** كل صفحة جدول تُطبع مباشرة (Ctrl+P). افتح مكبّر الصفحة إن كان الجدول عريضًا.
- **PDF:** من المتصفح: «طباعة ▸ حفظ كملف PDF» → ملف جاهز للإرسال في مجموعات أولياء التلاميذ.
- **USB / نسخة مضغوطة:** المجلد مستقل بذاته؛ انسخه كاملًا (بما فيه `stylesheet.css` إن وُجد).

## ملاحظات مهمّة

| المسألة | التفصيل |
| --- | --- |
| لا يوجد تحكّم صلاحيات | كل من يملك الوصول للمجلد يرى كل الجداول. إن أردت فصلًا لكل دور لاحقًا فالحل هو الخيار (ب) أو (ج) في `docs/UI-PLAN.md`. |
| المجلد غير سرّي | لا تضع فيه ملفات أخرى حسّاسة. |
| النسخ الاحتياطي | احتفظ بكل مجلد نشر مؤرّخ؛ حذف مجلد = حذف أرشيف ذلك الجدول. |
| التحديث | عند تغيير الجدول أنشئ نشرًا جديدًا ثم — عند الحاجة — أشر إلى المجلد الأحدث فقط (مثلًا بتغيير ملف `latest.txt` أو اسم المجلد). |
| ملفات HTML لـ FET نفسها | تتضمّن ميزاتها الكاملة (ألوان، وسوم، ملاحظات)؛ صفحتنا العربية مجرّد بوابة تنظيمية لها. |

## ما لم يُنجَز بعد (مقترحات تالية)

1. زر **«نشر تلقائي بعد كل توليد»** من الإعدادات (بلا حوار).
2. **`latest.html`** يُحدَّث تلقائيًا ليشير إلى آخر نشر (حتى لا يبحث المستخدمون عن المجلد).
3. **تقرير تدقيق**: قائمة الملفات المنشورة + بصماتها في ملف `manifest.txt`.
4. **مشاركة داخل البرنامج** (خيار ب): خادم عرض صغير على المنفذ 8080 داخل الشبكة المحلية.

كل ما سبق لا يحتاج تغيير أي سطر في المحرّك.
