# Open-Timetable

مشروع مفتوح المصدر لإنشاء وإدارة الجداول الزمنية الدراسية.

## الحالة

المستودع في مرحلته الأولى: تم تجهيز **محرّك التوليد** الذي سنبني عليه، وهو برنامج
[FET — Free Timetabling Software](https://lalescu.ro/liviu/fet/) الإصدار **7.12.0**
(رخصة AGPL v3)، محفوظ كأرشيف رسمي موقّع في:

```
vendor/fet/fet-7.12.0.tar.xz
```

انظر `vendor/fet/README.md` للتفاصيل: التحقق من البصمة، فك الضغط، البناء، واستخدام
الوضع السطري `fet-cl`.

## الخطوات التالية المقترحة

1. فك الأرشيف وبناء `fet-cl` (محرّك التوليد بوضع سطر الأوامر).
2. بناء واجهة ويب لإدخال البيانات (أساتذة، مواد، صفوف، قاعات، قيود).
3. توليد ملف `.fet` من الواجهة، تشغيل المحرّك، ثم عرض الجداول الناتجة.
4. إدارة الحسابات والصلاحيات (مدير، أستاذ، طالب) وعرض الجداول والطباعة والتصدير.

## الرخصة

- كود هذا المشروع: يُحدَّد لاحقًا.
- FET (داخل `vendor/fet/`): GNU AGPL v3 — راجع `vendor/fet/README.md` قبل أي توزيع أو
  تشغيل كخدمة شبكية.
